## 決策

- `Meta 廣告` 結果卡片改為依 `activeTab` 強制控制欄位顯示，`meta_ad` tab 一律顯示 `Description` 區塊，不再依賴回傳 label 狀態決定。
- `Meta 廣告` 的前端結果 UI 改成更清楚的欄位卡片版型，將 `Headline / Primary text / Description / CTA / URL` 視覺上拆開，降低誤判成缺欄位的機率。
- 前端靜態資產改加版本 query，`localStorage` key 也版本化，避免瀏覽器繼續吃到舊版 `app.js` 或舊欄位結果，導致 `Meta 廣告` 看起來像沒更新。
- 文案風格收斂為僅保留 `brand`、`conversion` 兩種；前端 radio、前後端驗證與 fallback tone 分支已同步移除 `promo`。
- writer / formatter prompt 新增硬規則：廣告文案不得提及任何價格、售價、原價、優惠價、折扣或金額；正式站後端也加上價格詞檢查。
- `bridge-server.js` 已改成完整收集商品圖（上限 `MAX_PRODUCT_IMAGES`，預設 `30`），並預設對全部候選商品圖做 OCR（`OCR_ALL_IMAGES=true`），vision 則只取高價值前幾張。
- 已接入 `ScreenshotOne` fallback 架構：當產品頁 HTML 抓取遇到 `401/403/429` 或 timeout 時，可改抓 full-page screenshot slices，並對 slices 做 OCR 與部分 vision 分析。
- 正式站程式碼已部署新版 screenshot fallback 邏輯，但目前 production `pm2 env` 尚未設定 `SCREENSHOTONE_ACCESS_KEY`，所以 fallback 尚未啟用。
