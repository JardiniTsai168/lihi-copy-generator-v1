# 2026-07-17

## 決策

- 將正式可部署後端從本機 `express + cloudflared tunnel` 轉為 Cloudflare Worker 結構。
- 保留既有前端與 `/api/health`、`/api/generate-copy` contract，不重做 UI。
- live 模式不再綁定本機 OpenClaw tool，改為由 Worker 透過 `BECK_V1_ENDPOINT` 與 secret 代理外部 agent endpoint。
- 若 live endpoint 失敗，Worker 先自動降回 mock，避免 demo 直接壞掉。

## 驗證

- 已新增 `src/worker.js`、`wrangler.jsonc`、`.dev.vars.example` 與 `npm run deploy` 所需基本結構。
- API health response 已對齊前端使用的 `endpointMode` 欄位。
- `/api/generate-copy` response 已對齊前端使用的 `ok`、`mode`、`prompt`、`output` 欄位。
- 已先針對 GitHub Pages 桌機卡頓做第一輪前端減載：移除大面積 `backdrop-filter`、取消固定模糊光暈、把 prompt 預覽改成 debounce 更新。
- 前端已補上「本次結果：Live / Mock / Mock Fallback」明確標示，避免把 fallback 文案誤判成真實 agent 產出。
- 已定位前端無 `/api/generate-copy` request 的根因：`public/app.js` 的 `getApiUrl()` 用 `new URL(path, "./api/")`，瀏覽器會丟 `Invalid URL`，因此送出前就直接落入 mock fallback。
- 已修正 `getApiUrl()` 改為先以 `window.location.href` 解析相對 base，再組出絕對 API URL；修正後已重新 deploy Worker 靜態資產。
- 修正後直接對公開 Worker API 測試，已確認可回 `\"ok\":true` 與 `\"mode\":\"live\"`。
- `bridge-server.js` 已補上頁面分析 pipeline：先抓 `productUrl` HTML，再抽 title/meta/heading/價格訊號/圖片資訊，並將結果組進 live prompt。
- bridge 已補上本機 `tesseract` OCR：會抓前幾張主要商品圖做 OCR，再把圖上文字一併餵給 `beck-v1`。
- 以 `https://belfortsky.com/product/pumpkin` 實測，新 prompt 已明確帶入頁面摘要、價格訊號與圖片 OCR 文字，live API 可正常回稿。
- 前端已新增「本次頁面分析摘要」卡片，live 結果會顯示頁面摘要、頁面標題/描述、價格訊號與圖片 OCR，方便直接檢查本次文案依據。
- 已重新 deploy Worker 靜態資產；公開頁面版本更新後可直接在結果區看到分析摘要卡。
