## coloring bot / abuse 防護補強

- 2026-08-03 深夜，依使用者要求，著色圖服務新增第二層 bot / abuse 防護，不只保留「每裝置每天 5 次」，也補上短時節流與請求驗證。
- 後端新增保護：
  - `GET /coloring-session` 會發短效 session token，前端建立 job 與查 job 都必須帶 `X-Coloring-Session`
  - 同 IP 限速：
    - 視窗：`10 分鐘`
    - 上限：`10` 次建立 / 同步產圖請求
  - 同 IP 可疑請求記分與暫時封鎖：
    - 無 `Origin/Referer`
    - 明顯腳本 `User-Agent`（如 `curl` / `python` / `postman`）
    - 無效 session token
  - 同裝置同時只允許 `1` 個 active 產圖任務，避免 queue 被同裝置重複塞爆
- request 流程現在會同時檢查：
  - 本站 cookie
  - 同源來源
  - 短效 session token
  - IP 速率
  - active job 數
- 前端補上：
  - 開頁後先取 `coloring-session`
  - resume job / 建立 job / 舊同步產圖路徑都會自動帶 token
  - 新錯誤訊息：
    - `頁面驗證已過期，請重新整理後再試一次`
    - `目前這個網路來源請求太頻繁，請稍後再試`
    - `這台裝置目前已有產圖任務進行中`
- 測試補強：
  - `session token` 綁定裝置
  - `validateColoringRequest` 正常瀏覽器通過
  - `IP limit` 超量時返回 block
  - `同裝置第二個 active job` 被擋
  - `script traffic suspicion score` 命中
