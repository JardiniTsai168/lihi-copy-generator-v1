
## copy.bktsai.link 正式站脈絡
- `copy.bktsai.link` 已作為正式前端 + API 同網域入口；根路徑提供前端頁，`/health` 提供 live 狀態，`/generate-copy` 提供生成 API。
- 正式站目前的主頁方向是乾淨版文案產生器，不把 debug 資訊混在主流程內。
- 主頁 header 文案定為 `廣告文案產生器 | lihi 實驗室`，狀態檢查直接放在標題右側；`V1`、右側額外框、舊 hero 說明文都已移除。
- 主頁表單已縮短：主要賣點先露出 3 個，其餘欄位收進可展開區，目的是縮短左欄長度。
- 主頁輸出區要維持乾淨、可直接閱讀；「這裡會顯示客戶版文案引擎生成的最終文案」這類說明句已拿掉，文案排版已往乾淨閱讀格式調整。
- 新增 `/detailed` 頁面，承接 `prompt 預覽` 與 `頁面分析摘要` 等 debug/review 資訊；主頁只保留核心生成器流程。

## 圖片型電商頁理解方向
- 使用者明確希望系統能解讀「文字印在圖片上的電商銷售頁」，不只吃 HTML 文字。
- 目前流程已朝混合分析前進：先抓 HTML 的 title/meta/price/heading，再抓主要商品圖做 OCR，並用 vision 模型直接抽產品文案、賣點、包裝與規格線索。
- 已做過一輪 OCR 雜訊過濾，前端摘要改為優先顯示結構化圖片線索，不再優先顯示原始亂碼 OCR。
- 目前已把圖片資訊整理成結構化欄位，例如：品名/關鍵字、可驗證賣點、規格/使用線索，目標是讓生成文案更準確。
- 使用者對目前文案效果的回饋是「先這樣可以」，代表現階段重心可先放在前端體驗與正式頁面整理。
