## 2026-07-20
- `beck-v1` / `bridge-server.js` 的 `generate-copy` 流程已往「HTML 優先、截圖 fallback」方向演進：先抓產品頁 HTML、完整收集商品圖（上限 30）、全量候選圖做 OCR、只挑高價值前幾張做 vision；若 HTML 抓取遇到 `401/403/429` 或 timeout，改走 ScreenshotOne full-page screenshot slices，再對 slices 做 OCR，並挑部分 slices 做 vision。
- 產品決策：不採用「所有圖片全送 vision」，而是「全量抓圖 + 全量 OCR + 部分 vision + screenshot fallback」，在資料完整度、成本、延遲之間取平衡。
- 已部署的程式仍有一個 production 缺口：正式站尚未設定 `SCREENSHOTONE_ACCESS_KEY` 與 `SCREENSHOTONE_ENABLED=true`，因此 ScreenshotOne fallback 程式碼雖已接好，但尚未真正啟用；啟用後需在 `/var/www/beck-v1` 執行 `pm2 restart beck-v1 --update-env`。
