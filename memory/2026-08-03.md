# 2026-08-03

- `creative.bktsai.link` 這輪已將素材風格定為 4 種：`clean / bold / warm / luxury`，`editorial` 已移除。
- 四種風格的 prompt 已改為「固定骨架 + 多維 random options」；隨機維度已擴到 `構圖 / 背景 / 色彩 / 光線 / 鏡頭視角 / 材質語感 / 輔助元素 / 文字版位 / 字體情緒 / 視覺節奏`，並要求同風格連續生成時至少有 3 個維度明顯不同。
- `luxury` 與 `bold` 曾出現生成結果過度偏黑底的問題；已調整 random 候選與 prompt 約束，明確避免在未指定深色時默認落成全黑或近黑畫面。
- 圖像文案規則已補強：素材圖上至少要有 2 到 3 個賣點短句，優先使用表單 `benefits`，不足時再從主文案 / source body 萃取，但不可自行發明新功效。
- 模特兒設定目前定為 4 種：`none / adult / family / hand`，且每種都已做成「固定骨架 + 細分 random」；同類型連續生成時至少要有 2 個維度明顯不同。
- 右側素材尺寸 tabs 的顯示規格已定版為「只顯示比例 + 平台，不顯示像素尺寸」：`1:1 (Fb, IG)`、`4:5 (IG)`、`9:16 (Threads, Reels, Stories)`、`1.91:1 (Google Ads)`。
- `coloring.bktsai.link` 這輪已收斂成單一路徑：固定使用 `openai/gpt-5.4-image-2` 搭配 `quality=low`，測試用的 model / quality dropdown 已全部移除，前後端都只允許這組設定。
- `coloring.bktsai.link` 的互動流程已定版為上下兩區：第一區先上傳圖片並完整預覽（`contain`），上傳後隱藏拖拉上傳框，只保留圖片與刪除按鈕；第二區在使用者點擊生成後於下方顯示著色卡結果。
- `coloring.bktsai.link` 的著色卡 prompt 方向最後定為「主體細節少一點，但保留可辨識背景」，背景以較大塊、可辨識、可上色的場景元素為主，避免只剩主體或過多碎細節。
- `coloring.bktsai.link` 結果資訊區已保留並定版為同排顯示 `生成模型 / 本次費用 / 輸出模式`，另外新增 `產出耗時`，顯示單張圖片實際花費秒數而不是完成時間點。
- `coloring.bktsai.link` 的標題與文案版面已調整：`powered by lihi.io` 放在 `lihi 實驗室` 標題右側，原本標題下方流程文案移除，頁面整體以更精簡的單任務生成流程為主。
